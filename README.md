# Garg Fabricators & Hardware - Website

Single-file website (HTML5, CSS3, vanilla JS). No build step, no backend.

## Run
Open `index.html` in a browser.

## Deploy on Netlify
Drag and drop this folder on app.netlify.com/drop, or connect the repo. `netlify.toml` is included.

## Edit
- WhatsApp number: search `919807112233` in `index.html`.
- Products and categories: `CATS` and `P` arrays inside the `<script>`.
- Images are embedded in `index.html` as base64 (cropped from the design mockup). Originals are in `assets/`. Replace them with real showroom and product photos.
- Check business hours (9 AM - 9 PM) before publishing.
